## SECTION 5: TRANSFORMATION MODES (ADAPTIVE AWARENESS)
**[COMPONENT TYPE: Tabbed interface or horizontal scrolling cards - each mode gets its own card]**

### Section Heading
**One Tool. Infinite Workflows.**

### Section Subheading
Ember Echo adapts to your context automatically. Writing code? It optimizes for technical accuracy. Drafting emails? Professional formatting. Chatting with AI? Clear, conversational prompts.

### Mode 1: AI Assistant Mode (Default)
**When to use:** General ChatGPT/Claude conversations, brainstorming, Q&A

**What it does:**
- Removes filler words ("um", "uh", "like")
- Structures rambling thoughts into clear questions
- Preserves your intent and personality
- Optimizes for conversational AI

**Example Transformation:**
- **You say:** "So uh I'm trying to figure out how to like improve my content strategy for LinkedIn and I don't know where to start"
- **Echo outputs:** "I need help developing a content strategy for LinkedIn. Where should I start? What are the key components of an effective LinkedIn content plan?"

### Mode 2: Email Mode
**When to use:** Professional emails, client communication

**What it does:**
- Adds professional structure (greeting, body, closing)
- Corrects grammar and tone
- Formats paragraphs and lists
- Adds sign-off template

**Example Transformation:**
- **You say:** "Hey I wanted to follow up about the meeting yesterday and see if we can move forward with the proposal"
- **Echo outputs:**
  ```
  Hi [Recipient],

  I wanted to follow up on yesterday's meeting. Are we ready to move forward with the proposal we discussed?

  Looking forward to hearing from you.

  Best regards,
  [Your Name]
  ```

### Mode 3: Vibe Coding Mode
**When to use:** Programming sessions, technical documentation, code discussions

**What it does:**
- Preserves technical accuracy (function names, variables, syntax)
- Uses screen context to correct code references
- Maintains technical terminology
- Optimizes for technical AI prompts

**Example Transformation:**
- **You say:** "I need to refactor the user auth function to handle edge cases when the token expires"
- **Echo outputs:** "Refactor the `userAuth()` function to handle edge cases when authentication tokens expire. Include proper error handling and token refresh logic."

### Mode 4: Rewrite Mode
**When to use:** Long-form content, blog posts, articles

**What it does:**
- Improves sentence structure and flow
- Breaks down run-on sentences
- Enhances clarity and readability
- Maintains your voice

### Mode 5: Custom Modes
**When to use:** Your unique workflow

**What it does:**
Create unlimited custom transformation prompts with your own rules, formatting, and optimization preferences.

### Adaptive Awareness (Auto-Switching)
**[CALLOUT BOX]**
Echo detects what you're doing and switches modes automatically:
- Working in VS Code? → Vibe Coding Mode
- Browsing Gmail? → Email Mode
- ChatGPT open? → AI Assistant Mode
- Say "email mode" while recording? → Instant override

**Trigger types:** Voice keywords, URL patterns, active applications

- Add custom words to your personal dictionary

**Benefit:** Echo uses multiple context sources to improve accuracy and transformation quality.

- **Clipboard:** Understands what you just copied

**Benefit:** Work the way you want. Multiple recording triggers and modes.

**Options:**
- **Hotkeys:** Quick tap (hands-free) or press-and-hold (push-to-talk)

- **Menu bar:** Click to record

## DEVELOPER HANDOFF: COMPONENT RECOMMENDATIONS & CONVERSION OPTIMIZATION

### Technical Component Stack Recommendations

#### Hero Section
- **Component:** Full-width hero with gradient background
- **Elements:** Centered headline (large, bold), subheadline (medium weight), dual CTAs (primary + secondary), optional video/GIF demo
- **Conversion tip:** Video demo auto-plays on scroll-into-view, 10-15 seconds max, shows transformation in action

#### Problem/Solution Storytelling
- **Component:** Two-column layout (text + visual)
- **Elements:** Callout boxes for bad prompt examples, bold pullquotes for key insights
- **Conversion tip:** Use emotional storytelling to connect with reader's pain point before presenting solution

#### How It Works (3-Step Process)
- **Component:** 3-column card layout with icons
- **Elements:** Step number, icon, title, description, example prompt (expandable or tooltip)
- **Conversion tip:** Show concrete before/after examples, use animation to show transformation

#### Key Benefits Grid
- **Component:** 4-column responsive grid (stacks on mobile)
- **Elements:** Icon, benefit title (short), description (1-2 sentences)
- **Conversion tip:** Focus on outcomes, not features. "Work 3× faster" not "Speech-to-text API"

#### Transformation Modes (Adaptive Awareness)
- **Component:** Tabbed interface OR horizontal scrolling cards
- **Elements:** Mode name, description, example transformation (before/after)
- **Conversion tip:** Make transformations interactive—let users click to see examples

#### Power User Features
- **Component:** Alternating left-right feature blocks with screenshots
- **Elements:** Screenshot/visual on one side, feature description on other, alternates per feature
- **Conversion tip:** Use real app screenshots to build trust and show polish

#### Comparison Table
- **Component:** Responsive table with sticky header (on scroll)
- **Elements:** Checkmarks (✓) and X marks (✗), green highlight for Ember Echo column
- **Conversion tip:** Use visual contrast to make Echo's advantages immediately obvious

#### Social Proof
- **Component:** Testimonial cards (3-column grid or carousel)
- **Elements:** Quote, attribution (name + title + photo if available), optional company logo
- **Conversion tip:** Use real testimonials with photos for credibility

#### Pricing/CTA Section
- **Component:** Centered pricing card with feature list
- **Elements:** Large CTA button, feature checklist, trust signals below CTA
- **Conversion tip:** Emphasize "free" and "no credit card" to reduce friction

#### Final CTA Banner
- **Component:** Full-width section with contrasting background
- **Elements:** Headline, subheadline, CTA button, supporting text
- **Conversion tip:** This is last chance to convert—make it bold and action-oriented

### Conversion Optimization Notes

1. **Above the fold:** Hero should immediately communicate the "tired prompts" problem and solution. Don't bury the lede.

2. **Social proof placement:** Sprinkle testimonials throughout, not just in one section. Build trust progressively.

3. **CTA repetition:** Primary CTA ("Download Free") should appear:
   - Hero section
   - After "How It Works" section
   - After comparison table
   - Final CTA banner

4. **Friction reduction:**
   - Emphasize "free" and "no credit card"
   - Show macOS version requirement clearly
   - Link to quick FAQ for objection handling

5. **Visual hierarchy:**
   - Use contrasting colors for CTAs (high visibility)
   - Break up text with visuals, callout boxes, quotes
   - White space is your friend—don't cram content

6. **Mobile optimization:**
   - All grids should stack vertically on mobile
   - CTAs should be thumb-friendly (min 44px height)
   - Hero video should be optional (data usage)

7. **Performance:**
   - Lazy load images below the fold
   - Optimize video/GIF file sizes
   - Use WebP format for screenshots

8. **Analytics tracking:**
   - Track scroll depth (how far users read)
   - Track CTA clicks by location (hero vs. mid-page vs. final)
   - Track video play rate (if using demo video)
