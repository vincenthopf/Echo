Echo gives you full control over how it records, transcribes, and delivers your text. Settings are accessed by clicking **Settings** in the sidebar, which opens a tabbed interface with four tabs.

## Settings Tabs

### [General](/docs/settings/general)

Manage launch at login, automatic updates, system permissions, privacy controls, backup and restore, appearance options, and diagnostics.

### [Recording](/docs/settings/recording)

Choose your microphone, set up device priority for automatic switching, adjust microphone sensitivity, configure keyboard shortcuts, and control media behavior during recording.

### [Transcription](/docs/settings/transcription)

Browse, download, and select transcription models. Configure language settings, output formatting, and voice activity detection.

### [Intelligence](/docs/settings/intelligence)

Connect AI providers with API keys for AI Enhancement. View Adaptive Awareness status and configure transformation keyboard shortcuts.

## Tips

- Most settings take effect immediately -- no need to restart Echo.
- Many output and recording behaviors can also be configured per-profile in [Adaptive Awareness](/docs/adaptive-awareness), which overrides global settings when a profile is active.
- Use **Export Settings** in the General tab to back up your configuration before making major changes.
