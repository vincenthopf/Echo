The **Intelligence** tab in Settings is where you connect AI providers for AI Enhancement, access Adaptive Awareness management, and configure transformation keyboard shortcuts. Open Echo, go to **Settings** in the sidebar, then click the **Intelligence** tab.

## AI Provider Integration

Before you can use AI Enhancement, you need to connect at least one AI provider. This section lets you add API keys and select models.

1. Choose your provider from the **AI Provider** dropdown
2. Paste your API key into the **API Key** field
3. Click **Verify and Save**

Once connected, you'll see a green **Connected** badge next to the provider name. You can then select which model to use from the **Model** dropdown.

For detailed setup instructions including where to get API keys, see [Setting Up AI Providers](/docs/ai-enhancement/setup).

## Adaptive Awareness

This section provides a quick link to manage your Adaptive Awareness profiles, where AI Enhancement is configured per-profile.

- **Manage Profiles** -- Opens the Adaptive Awareness view in the sidebar
- **Restore defaults after each session** -- When enabled, Echo reverts enhancement and transcription preferences to whatever was configured before Adaptive Awareness was activated, after each recording session

For details on configuring AI Enhancement within profiles, see [Adaptive Awareness](/docs/adaptive-awareness).

## Transformation Shortcuts

These keyboard shortcuts are available while the recorder is visible during recording:

### Toggle Intelligent Transformation

Press **Command + E** to quickly enable or disable AI transformation during a recording session. This shortcut can be toggled on or off in this section.

### Switch Transformation Prompt

Press **Command + 1** through **Command + 0** to switch between your saved transformation prompts. The number corresponds to the order your prompts are saved -- Command + 1 activates the first prompt, Command + 2 the second, and so on up to Command + 0 for the tenth.

These shortcuts are only available while the recorder is visible.

## Tips

- If you're just getting started with AI Enhancement, **Gemini** is a good choice because it offers a free API key.
- Your API keys are stored securely in the macOS Keychain, not in plain text.
- You can add keys for multiple providers and switch between them at any time.
