Echo works with other tools on your Mac. You can trigger recordings hands-free using Siri Shortcuts, and connect your own transcription services through custom cloud models.

## What You Can Do

**Siri Shortcuts** let you start and stop Echo recordings using your voice, the Shortcuts app, or automations you build yourself. Say "Start Echo recording" to Siri, or wire Echo into a multi-step shortcut that runs on a schedule or in response to an event.

**Custom cloud models** let you connect any OpenAI-compatible transcription API to Echo. If you run your own transcription server or use a provider that Echo does not include by default, you can add it as a custom model and select it just like any built-in service.

## Getting Started

- To control Echo with Siri or the Shortcuts app, see [Siri Shortcuts](/docs/integrations/siri-shortcuts).
- To add your own transcription endpoint, see [Custom Cloud Models](/docs/integrations/custom-models).
