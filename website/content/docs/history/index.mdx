Every transcription you make in Echo is saved automatically. The **History** tab gives you a searchable, scrollable log of everything you have dictated, so you can find, copy, review, or delete past transcriptions whenever you need them.

## Browsing Your History

1. Open Echo and select **History** in the sidebar.
2. Your transcriptions appear in reverse chronological order, with the most recent at the top.
3. Each card shows a preview of the transcription text, the date and time it was created, and the audio duration.
4. Click any card to expand it and see the full text.

## Searching Transcriptions

Use the **Search transcriptions** field at the top of the History view to find specific entries. Echo searches both the original transcription and any AI-enhanced version, so you can find results regardless of which version contains the words you are looking for.

{/* Screenshot: Search bar with a query entered, showing filtered results */}

## Viewing Transcription Details

When you expand a transcription card, you get access to the full content and metadata:

- **Original** tab -- The raw transcription text exactly as it was spoken.
- **Enhanced** tab -- The AI-enhanced version (only appears if AI Enhancement was used for that transcription).
- **AI Request** tab -- The system prompt and user message sent to the AI model (only appears when applicable).

Use the **Copy** button next to the tabs to copy the currently visible text to your clipboard.

{/* Screenshot: Expanded transcription card showing the Original/Enhanced/AI Request tabs and the copy button */}

### Audio Playback

If the original audio recording is still available, an audio player appears at the bottom of the expanded card, letting you listen back to what you said.

### Metadata

Below the transcription text, you can see details about how the transcription was processed:

- **Configuration** -- Which Adaptive Awareness profile was active (if any).
- **Audio Duration** -- Length of the original recording.
- **Transcription Model** -- Which model processed the audio.
- **Enhancement Model** -- Which AI model enhanced the text (if applicable).
- **Prompt Used** -- The name of the AI prompt that was applied.
- **Transcription Time** -- How long the transcription took to process.
- **Enhancement Time** -- How long the AI enhancement took.

## Selecting and Managing Transcriptions

You can select one or more transcriptions using the circular checkbox on the left side of each card. Once you have a selection, a toolbar appears at the bottom with these actions:

- **Analyze** -- Opens a performance analysis view for the selected transcriptions, showing model speed comparisons and processing statistics.
- **Export** -- Saves the selected transcriptions as a CSV file.
- **Delete** -- Permanently deletes the selected transcriptions and their associated audio files.
- **Select All** / **Deselect All** -- Quickly select or clear all transcriptions (including those not currently loaded on screen).

{/* Screenshot: Selection toolbar showing Analyze, Export, Delete, and Select All buttons with a count of selected items */}

### Quick Actions

Right-click any transcription card to access a context menu with:

- **Copy Enhanced** -- Copies the AI-enhanced text (only available if enhancement was used).
- **Copy Original** -- Copies the original transcription text.
- **Delete** -- Removes the transcription.

## Loading More Results

History loads transcriptions in batches for performance. If you have more transcriptions than are currently shown, a **Load More** button appears at the bottom of the list. Click it to load the next batch.

## Tips

- Use search to quickly find a transcription by any word or phrase -- it checks both the original and enhanced text.
- Right-click a card for fast copy access without needing to expand it first.
- Select multiple transcriptions and use **Analyze** to compare performance across different models or time periods.
