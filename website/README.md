# Echo Website

Marketing site and documentation for [Echo](https://echo.vjh.io) — a native macOS voice-to-text app with offline transcription, AI enhancement, and adaptive awareness.

Built with Next.js, Fumadocs, and Tailwind CSS. Deployed to Cloudflare Pages via OpenNext.

## Development

```bash
pnpm install
pnpm dev
```

## Build & Deploy

```bash
pnpm build          # Next.js build
pnpm preview        # Cloudflare local preview
pnpm deploy         # Deploy to Cloudflare Pages
```
